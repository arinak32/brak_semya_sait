О текущей версии сайта

Эта страница описывает текущую версию сайта медицинского центра «Брак и Семья». Сайт содержит сведения о специалистах, услугах, ценах и способах связи с центром.

Данные при просмотре

В текущей версии отсутствуют формы заявок, регистрация, личный кабинет и загрузка документов. Поиск по каталогам услуг и исследований выполняется внутри браузера. Сайт не отправляет поисковые запросы в клинику или лаборатории.

Технические сведения

При открытии страниц браузер обращается к сервису размещения GitHub Pages. GitHub сообщает, что при посещении сайтов GitHub Pages IP-адрес посетителя записывается и хранится для целей безопасности. Условия сервиса приведены в политике конфиденциальности GitHub.

Переходы на другие сервисы

Кнопки связи открывают телефонное приложение, Telegram или WhatsApp. Ссылки на лаборатории и карту открывают соответствующие внешние сайты. При переходе и дальнейшем использовании этих сервисов действуют их условия обработки данных. Содержание вашей переписки через сайт не передаётся.
