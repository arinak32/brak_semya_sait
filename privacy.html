О текущей версии сайта

Эта страница описывает демонстрационную версию сайта медицинского центра «Брак и Семья». Сайт содержит сведения о специалистах, услугах, ценах и способах связи с центром.

Данные при просмотре

В текущей версии отсутствуют формы заявок, регистрация, личный кабинет и загрузка документов. Поиск по каталогу исследований выполняется внутри браузера. Сайт не отправляет поисковые запросы в клинику или лаборатории.

Технические сведения

При открытии страниц браузер обращается к сервису размещения GitHub Pages. GitHub может обрабатывать IP-адрес, сведения об устройстве и браузере, время запроса и сведения о посещённых страницах согласно своей политике. Условия сервиса приведены в политике конфиденциальности GitHub.

Переходы на другие сервисы

Кнопки связи открывают телефонное приложение, Telegram или WhatsApp. Ссылки на лаборатории и карту открывают соответствующие внешние сайты. При переходе и дальнейшем использовании этих сервисов действуют их условия обработки данных. Содержание вашей переписки через сайт не передаётся.

Согласование перед запуском

Для рабочей версии клинике необходимо утвердить сведения об операторе персональных данных, целях и правовых основаниях обработки, составе данных, сроках хранения, получателях, порядке реализации прав и контакте для обращений. Окончательный текст должен учитывать фактический хостинг и подключённые сервисы.
